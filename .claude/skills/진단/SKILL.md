# 진단 — 고치기 전에 전부 찾는다

받은 파일: $ARGUMENTS

대상 폴더: `C:\edata9-work\cleaner\data` — 받은 파일은 이 폴더에서 찾는다.

파일 이름이 비어 있거나 이 폴더에 그 파일이 없으면, 어떤 파일인지 묻고 멈춘다.

## 늘 지킬 것

- 아무것도 고치지 않는다.
- 처리 방법을 제안하지 않는다.
- 원본 파일은 열기만 한다.

## 1. 파일을 읽는다

- CSV: 인코딩(UTF-8 / BOM 유무 / CP949)과 줄바꿈을 확인하고 적는다. 줄마다 칸 수가 같은지 센다.
- 엑셀: 시트가 몇 개인지 적고, 시트마다 따로 진단한다. 머리글이 두 줄인지, 맨 위에 제목 줄이 있는지 처음 몇 줄을 눈으로 본다.
- 행 번호는 사람이 파일을 열었을 때 보이는 번호(엑셀 행 번호, CSV 줄 번호)로 적는다.
- 계산 결과를 화면에 바로 찍으면 한글이 깨질 수 있다. 결과는 UTF-8 파일로 쓴 뒤 읽는다.

## 2. 다섯 증상을 칸마다 센다

칸마다 다섯 증상의 **건수**와 **예**(행을 알아볼 수 있는 ID + 실제 값, 최대 세 개)를 적는다. 해당 없으면 `0`, 그 칸에 맞지 않는 증상이면 `–`.

| 증상 | 세는 법 |
|---|---|
| **빈칸** | 값이 없거나 공백만 있는 칸. 앞뒤 공백이 붙은 값도 따로 센다 |
| **튀는 값** | 숫자 칸에서 사분위범위(IQR) 1.5배 울타리 밖. 울타리 값과 중앙값을 각주에 적는다. **«튀는 값»은 «틀린 값»이 아니다** — 남들과 다를 뿐이라는 뜻으로만 쓴다 |
| **섞인 형식** | 한 칸 안에 여러 모양이 섞였는가. 정수 / 소수 / 숫자+단위(`5개`) / 날짜 모양(`YYYY-MM-DD`, `YYYY.MM.DD` …) / 글자. 모양별 개수를 적는다. 날짜는 실제 있는 날짜인지, 범위(가장 이른 날 ~ 가장 늦은 날)도 적는다 |
| **중복** | ① 모든 칸이 같은 행 ② ID 칸만 빼고 같은 행 ③ ID 칸 값이 겹치는 행. 셋을 따로 센다 |
| **표기** | 같은 뜻을 다르게 적은 값. 대소문자·공백 차이만 보지 말고, **값 목록을 눈으로 읽어** 뜻이 같은 다른 말을 찾는다 — 예: `수료`·`완료`, `미수료`·`미완`, `Y`·`y`·`예`·`TRUE`. 기계로는 못 찾으니 반드시 목록을 읽는다 |

## 3. 값 목록

종류가 **서른 가지 이내**인 칸은 값 전부와 개수를 많은 순으로 적는다. 빈칸도 하나의 값으로 넣는다. 서른 가지가 넘는 칸은 «몇 종이라 뺐다»고만 적는다.

## 4. 칸 사이 모순 — 먼저 묻는다

진단표를 쓰기 전에 사용자에게 묻는다.

> 칸 사이에 «이래야 한다»고 정한 것이 있나요? 예: «이수시간이 0이면 수료여부는 미수료여야 한다»

- **사용자가 정한 것만 센다.** 내가 규칙을 지어내 세지 않는다.
- 규칙마다 어긴 행의 건수와 예를 적는다. 규칙에 걸릴 행이 아예 없으면(예: 조건 칸에 빈칸이 하나도 없음) 그렇다고 적는다.
- 같은 뜻의 다른 표기(2단계 «표기»)가 있으면 규칙을 적힌 그대로 셌는지, 같은 뜻까지 묶어 셌는지 밝힌다.
- 정한 것이 없다고 하면 «정한 것 없음 — 세지 않음»으로 적는다.

## 5. 결과

### 화면

진단표 **하나**. 행은 칸, 열은 `빈칸 · 튀는 값 · 섞인 형식 · 중복 · 표기 · 칸 사이 모순`. 맨 아래에 «행 전체» 줄을 두고 행 단위 중복을 적는다.

```
| 칸 | 빈칸 | 튀는 값¹ | 섞인 형식 | 중복 | 표기 | 칸 사이 모순 |
|---|---|---|---|---|---|---|
| 이수시간 | 9: AG039 · AG040 · … | 5: AG031 -12.0 · AG059 9999.0 · … | 0 | – | – | ① 5 |
| 수료여부 | 0 | – | 0 | – | 28: 완료 14 · 미완 14 | ① 5 |
| 행 전체 | – | – | – | 완전 중복 0 · ID 빼고 같은 행 0 | – | – |
```

표 아래에 차례로:
1. 칸 사이 모순 — 규칙마다 건수와 어긴 행
2. 각주 — 튀는 값 울타리, 파일 정보(행 수 · 인코딩 · 시트)
3. 값 목록 (3단계)
4. 정한 규칙에는 없지만 눈에 띈 것 — **있는 사실만**, 한 줄씩

### 파일

화면과 같은 내용을 `진단/[파일이름]_진단.md` 로 저장한다. `[파일이름]`은 확장자를 뺀 이름이다 (`교육이수로그.csv` → `진단/교육이수로그_진단.md`). 맨 위에 원본 경로와 진단한 날짜를 적는다.
